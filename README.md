# Webradio Concordia Management System

Version prototype fonctionnelle locale.

## Lancer
Ouvrir `index.html` dans un navigateur.

## Connexion démo
Email: admin@webradio.local
Mot de passe: webradio123

## Inclus
Site public, login, dashboard, membres, comités, projets, tâches, planning, interviews, calendrier, documents, recherche et données de démonstration.

## Important
Le login et les données sont locaux (sessionStorage/localStorage). Pour un vrai déploiement multi-utilisateur, remplacer l'authentification locale par Supabase ou un autre backend sécurisé.
